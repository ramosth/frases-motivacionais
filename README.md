Projeto da aula 01 da disciplina de **Desenvolvimento Web** do **Serratec (2021)**. Foi meu primeiro contato com React.

Uma página onde o usuário **cadastra frases motivacionais** com o autor, e elas aparecem em uma lista com a data de criação.

## Destaques técnicos

- Primeiros componentes funcionais: `Card`, `Formulario`, `FraseMotivacional` e `Rodape`
- Estado com `useState`, comunicação filho → pai por *callback* e renderização de listas com `map`

## Como executar

```bash
npm install
npm start
```

A aplicação abre em `http://localhost:3000`.
